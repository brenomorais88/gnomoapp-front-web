# Gnomo Logo Assets

Pacote com SVG editável e PNG exportado das principais versões do logo do app Gnomo.

## Pastas

- `svg/`: arquivos vetoriais editáveis para abrir no Figma, Illustrator, Inkscape ou usar direto no frontend.
- `png/`: versões em alta resolução com fundo conforme o arquivo.
- `app-icons/`: tamanhos comuns para app icon iOS/Android/PWA.
- `favicon/`: favicons em PNG e ICO.

## Cores

- Azul profundo: #2563EB
- Roxo: #7C3AED
- Verde: #16A34A
- Navy/texto: #0F172A
- Cinza: #6B7280

## Observação importante

Os SVGs deste pacote foram recriados como vetores editáveis a partir da direção visual aprovada. Eles não são uma extração perfeita com layers do PNG gerado por IA, porque imagens geradas são rasterizadas. Para produção final, revise os SVGs no Figma e ajuste curvas, espaçamentos e tipografia conforme necessário.
